¿Qué significan estos factores?

Autorregulación académica

Representa la capacidad para organizar tareas, mantener hábitos de estudio y cumplir actividades académicas.

✔ A mayor puntaje: mayor dificultad para mantener hábitos de estudio y organización.
✔ A menor puntaje: mayor capacidad para organizar tareas y mantener hábitos de estudio.

Postergación de actividades

Representa la tendencia a retrasar o dejar para después las actividades académicas.

✔ A mayor puntaje: mayor tendencia a retrasar o postergar actividades académicas.
✔ A menor puntaje: menor tendencia a procrastinar y mayor cumplimiento de actividades.
